サブスクリプションを復元する

新しいiPhoneや再インストール後は、同じApple IDでKeygel → 設定 → 購入を復元。

サブスクリプションを解約する

iOSの設定 → 自分の名前 → サブスクリプション → Keygel。更新の24時間前までに解約してください。

無料トライアル

無料トライアル中に解約すれば、料金はかかりません。

リマインダーが届かない

Keygel → 設定 → 毎日のリマインダーと、iOSの設定 → 通知 → Keygelを確認してください。

振動を感じない

Keygel → 設定 → 振動ガイドと、iOSの設定 → サウンドと触覚で振動が有効か確認してください。

進歩をリセットする

Keygel → 設定 → 進歩をリセット。このiPhoneからセッションと連続記録が削除されます。

医療ではなくウェルネス

Keygelはウェルネスアプリであり、医療機器ではありません。痛みや医学的な不安がある場合は医療の専門家に相談してください。
